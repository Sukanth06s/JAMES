# JAMES
James is a locally run personal AI system, that is capable of remembering and retrieval of relevant information. 
Im using ollama's models for the AI engine. Currently working on desiging the memory architecture.

## 🚀 Getting Started

Follow these quick steps to set up and run the application locally.

### 📦 1. Installation (First-Time Setup)

Open your terminal in the project root directory and run the following commands to install dependencies for both the frontend and backend orchestrator:

```bash
# Install frontend dependencies
cd frontend
npm install
```
```bash
# Return to root and install orchestrator dependencies
cd ..
npm install
```

---

### ⚡ 2. Running the Application

You don't need to open multiple terminal windows or change directories. Simply run the following command from the **root directory** to spin up both the backend and frontend simultaneously:

```bash
npm start
```

💡 **Tip:** To stop both servers completely when you are done, press `Ctrl + C` in your terminal or simply close the command window.
